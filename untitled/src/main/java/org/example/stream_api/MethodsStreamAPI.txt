Методы в stream api бывают промежуточные и терминальные.

ПРОМЕЖУТОЧНЫЕ МЕТОДЫ - обрабатывают данные и возвращают новый поток и позволяют строить цепочки операций. Промежуточные методы выполняются
только при вызове терминального метода.
Наиболее часто используемые промежуточные методы stream api:

1) filter(Predicate <T> predicate) - фильтрует элементы потока, оставляя только те, которые соответствуют заданному условию;

2) map(Function <T, R> mapper) - преобразует каждый элемент потока из одного типа данных в другой, с помощью функции mapper;

3) flatMap(Function <T, Stream <R>> mapper) - преобразует все элементы в поток, а затем объединяет все потоки в один поток;

4) distinct() - удаляет дубликаты из потока, оставляя только уникальные элементы;

5) sorted() - сортирует элементы потока в естественном порядке (если элементы реализуют интерфейс Comparable);

6) sorted(Comparator <T> action) - сортирует элементы потока с использованием компаратора;

7) limit(long maxSize) - ограничивает количество элементов в потоке до maxSize;

8) skip(long n) - пропускает первые n элементы в потоке;

9) peek(Consumer <T> action) - выполняет действие для каждого элемента, не изменяя сам поток. ЧЧасто используется для отладки;

10) dropWhile(Predicate <T> predicate) - пропускает элементы потока, пока они удовлетворяют условию.
Как только условие перестаёт выполняться, оставшиеся элементы возвращаются;

11) takeWhile(Predicate <T> predicate) - возвращает элементы потока до тех пор, пока они удовлетворяют условию.
Как только условие перестаёт выполняться, метод завершает свою работу;

12) mapToInt(ToIntFunction <T> mapper) - преобразует поток объектов в поток примитивов типа int.
Есть аналогичные методы mapToLong, mapToDouble;

13) boxed() - преобразует поток примитивных потоков (IntStream, LongStream, DoubleStream) в поток объектов (Stream <T>).

ТЕРМИНАЛЬНЫЕ МЕТОДЫ в Stream api java - это методы, которые завершают потоки и возвращают результат или выполняют финальное действие.
После вызова терминального метода поток нельзя использовать повторно.
Вот основные терминальные методы:

1) forEach(Consumer <T> action) - применяет действие к каждому элементу потока;

2) collect(Collector <T, A, R> collector) - преобразует поток в коллекцию или другую структуру данных;

3) toArray() - преобразует поток в массив;

4) reduce(BinaryOperator <T> accumulator) - сворачивает элементы потока в одно значение;

5) min(Comparator <T> comparator) и max(Comparator <T> comparator) - возвращает минимальный и максимальный элемент потока;

6) count() - возвращает количество элементов в потоке;

7) anyMatch(Predicate <T> predicate) - возвращает true, если хотя бы один элемент соответствует условию;
ё
8) allMatch(Predicate <T> predicate) - возвращает true, если все элементы соответствуют условию;

9) noneMatch(Predicate <T> predicate) - возвращает true, если ни один элемент не соответствует условию;

10) findFirst() и findAny() - возвращает первые или любой элемент потока.

Эти методы завершают работу с потоком.
