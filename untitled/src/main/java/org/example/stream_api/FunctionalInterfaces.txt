Функциональные интерфейсы - это интерфейсы, которые имеют только один абстрактный метод. Такие интерфейсы часто используются
для лямбды-выражения и создание ссылок.
Основные функциональные интерфейсы:

1) Consumer <T> - принимает один аргумент и не возвращает результат (абстрактный метод - void accept(T t));

2) Supplier <T> - не принимает аргументов, но возвращает результат (абстрактный метод - T get());

3) Function <T, R> - принимает один тип аргумента и возвращает другой тип (абстрактный метод - R apply(T t));

4) Predicate <T> - принимает один аргумент и возвращает boolean (абстрактный метод - boolean test(T t));

5) UnaryOperator <T> - частный случай Function, где входной и выходной параметр совпадают (абстрактный метод - T apply(T t));

6) BinaryOperator <T> - принимает два аргумента одного типа и возвращает результат того же типа (абстрактный метод - T apply(T t1, T t2));

7) BiFunction <T, U, R> - принимает два аргумента разных типов и возвращает результат третьего типа(абстрактный метод - R apply(T t, U u));

8) BiConsumer <T, U> - принимает два аргумента, и не возвращает результат (абстрактный метод - void accept(T t, U u));

9) Runnable - не принимает аргументы и не возвращает результат (абстрактный метод - void run());

10) Comparator <T> - используется для сравнения двух объектов (абстрактный метод - int compare(T o1, T o1)).

Функциональные интерфейсы активно используются в Stream API, многопоточности и других областях java, для упрощения кода
и повышения его читаемости.
